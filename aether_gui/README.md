# Aether GUI

رابط گرافیکی اندروید برای [Aether](https://github.com/CluvexStudio/Aether) با VPN کامل (کل ترافیک گوشی).

## چطور کار می‌کند
1. باینری رسمی Aether داخل APK بسته‌بندی می‌شود و به‌عنوان یک پردازش اجرا می‌شود (SOCKS5 روی `127.0.0.1:1819`).
2. وقتی Aether مسیر سالم پیدا کرد و پورت باز شد، یک `VpnService` بالا می‌آید.
3. `hev-socks5-tunnel` ترافیک TUN را به SOCKS5 می‌فرستد. DNS هم با mapdns از مسیر TCP می‌رود.
4. خود اپ از VPN مستثنا می‌شود تا ترافیک Aether در حلقه نیفتد.

## گرفتن APK
1. یک ریپوی GitHub بساز و محتوای این پوشه را push کن.
2. تب **Actions** ← workflow به نام **Build APK** (خودکار یا با Run workflow).
3. بعد از پایان، از بخش **Artifacts** فایل `aether-apk` را دانلود کن. برای اکثر گوشی‌ها `app-arm64-v8a-release.apk`.

## قبل از انتشار
- Aether با AGPL-3.0 منتشر شده؛ اگر APK را پخش می‌کنی، سورس این اپ هم باید با همان لایسنس در دسترس باشد.
- فایل `TRADEMARK.md` ریپوی Aether را درباره‌ی استفاده از نام و لوگو بخوان.
- اولین بیلد را روی گوشی واقعی تست کن. اگر `tool/build_tun2socks.sh` خطا داد، متغیر `HEV_REF` را روی یک تگ پایدار بگذار.
